Astra Blogs Library Demo

This demo loads astra-blogs-lib.js and calls library methods using a provided token and secret.

Result

Click a button to run a demo.

Library Examples

Use these examples with a valid token and secret that decrypt to the repo configuration.

const lib = new AstraBlogsLib({
  token,
  secret,
  indexCacheTTL: 600000,      // 10 minutes
  contentCacheTTL: 86400000,  // 24 hours
  useCache: true,
  storage: window.localStorage
});

Full token/secret initialization

Create a library instance with optional runtime settings, decrypt the config, and fetch blogs:

async function runDemo(token, secret) {
  const lib = new AstraBlogsLib({
    token,
    secret,
    indexCacheTTL: 600000,
    contentCacheTTL: 86400000,
    useCache: true,
    storage: window.localStorage
  });

  // Fetch the blog list from GitHub repository
  const blogs = await lib.getAllBlogs();
  console.log('Blogs:', blogs);

  if (blogs.length > 0) {
    const firstSlug = blogs[0].slug;
    const blogContent = await lib.getBlogContent(firstSlug);
    console.log('Blog content:', blogContent);
  }

  console.log('Current config:', lib.getConfig());
}

runDemo(token, secret).catch(console.error);

getAllBlogs()

Fetch the full index of published blog metadata from the configured repository. This returns an array of blog objects with title, slug, tags, and other metadata.

const blogs = await lib.getAllBlogs();
console.log(blogs);

getBlogContent(slug)

Fetch the markdown content for a single blog by slug. The result includes parsed YAML frontmatter metadata and the rendered markdown body.

const blog = await lib.getBlogContent('getting-started-with-react');
console.log(blog.metadata, blog.content);

getRecommendations(blogs, options)

Generate a ranked list of blog recommendations using tag overlap and optional user preference weights.

const recommendations = lib.getRecommendations(blogs, {
  count: 5,
  userPreferences: { react: 3, javascript: 2 }
});
console.log(recommendations);

trackReadBlog(tags, weight)

Record a reading interaction with blog tags to build or update personal recommendation preferences in storage.

lib.trackReadBlog(['react', 'web'], 1);
const prefs = lib.getUserPreferences();
console.log(prefs);

getUserPreferences()

Read the stored user preference profile that is used to personalize recommendations.

const preferences = lib.getUserPreferences();
console.log(preferences);

clearUserPreferences()

Clear any stored reading preferences from the configured storage mechanism.

lib.clearUserPreferences();

searchBlogs(blogs, query, options)

Filter a list of blogs by query text across title, description, tags, or other searchable fields.

const filtered = lib.searchBlogs(blogs, 'react', {
  searchFields: ['title', 'description', 'tags']
});
console.log(filtered);

filterByTags(blogs, tagFilter, mode)

Filter blogs by one or more tags, using either any-match or all-match logic.

const filteredTags = lib.filterByTags(blogs, ['react', 'javascript'], 'any');
console.log(filteredTags);

getConfig()

Return the current library configuration, excluding decrypted secrets.

console.log(lib.getConfig());

setConfig(newConfig)

Update runtime settings such as cache TTL or storage options without reinitializing the library.

lib.setConfig({ useCache: false });

clearCache(pattern)

Clear cached blog data from storage. Provide a key pattern to remove specific cache entries.

lib.clearCache('astra_blog_content_');
