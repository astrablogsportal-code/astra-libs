Library Examples

Use these examples with a valid token and secret that decrypt to the repo configuration.

const lib = new AstraBlogsLib({
  token,
  secret,
  indexCacheTTL: 600000,      // 10 minutes
  contentCacheTTL: 86400000,  // 24 hours
  useCache: true,
  storage: window.localStorage,
  allowedStatuses: ['published', 'in-review', 'draft'], // Custom statuses
  includeDrafts: false       // Set true to also include 'draft' posts
});

Full token/secret initialization

Create a library instance with optional runtime settings, decrypt the config, and fetch blogs:

async function runDemo(token, secret) {
  const lib = new AstraBlogsLib({
    token,
    secret,
    indexCacheTTL: 600000,
    contentCacheTTL: 86400000,
    useCache: true,
    storage: window.localStorage
  });

  // Fetch the blog list from GitHub repository
  const blogs = await lib.getAllBlogs();
  console.log('Blogs:', blogs);

  if (blogs.length > 0) {
    const firstSlug = blogs[0].slug;
    const blogContent = await lib.getBlogContent(firstSlug);
    console.log('Blog content:', blogContent);
  }

  console.log('Current config:', lib.getConfig());
}

runDemo(token, secret).catch(console.error);

getAllBlogs()

Fetch the full index of published blog metadata from the configured repository. This returns an array of blog objects with title, slug, tags, and other metadata. You can pass options like allowedStatuses and includeDrafts to dynamically filter by status.

// Fetch only published and in-review blogs
const blogs = await lib.getAllBlogs({ allowedStatuses: ['published', 'in-review'] });

// Or easily include drafts
const allBlogs = await lib.getAllBlogs({ includeDrafts: true });
console.log(blogs);

Event System

Subscribe to library lifecycle events to track cache hits, misses, fetch progress, and errors.

lib.on('cacheHit', key => console.log('Cache hit:', key));
lib.on('cacheMiss', key => console.log('Cache miss:', key));
lib.on('blogsLoaded', blogs => console.log('Blogs loaded:', blogs.length));
lib.on('error', error => console.error('Error:', error));
Register event listeners then run a fetch to see events.
